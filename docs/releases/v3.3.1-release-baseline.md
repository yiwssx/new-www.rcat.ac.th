# v3.3.1 Release Baseline

This document records the prepared release baseline for the v3.3.1 Content Operations workstream.

## Included scope

- Content Integrity v2 read-only rules and protected audit integration.
- Immutable revision schema and atomic revision recording at the Worker write boundary.
- Authenticated Admin revision history viewer.
- Guarded revision restore that creates a new Draft revision.
- Shared URL/link and content state/date validation contracts.

## Release boundary

The baseline is not production-released by this document. Do not create the `v3.3.1` tag or publish a release until the final integration-to-main pull request, protected production Worker preflight/release, and production verification have passed.

No production D1 mutation is performed by the development workstream.
